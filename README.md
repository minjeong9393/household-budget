# SCMJ 가계부

광고·추적·외부 CDN 없이 동작하는 부부 가계부 웹앱(PWA)입니다.
화면 하나(HTML)로 돌아가고, 기록은 기기(브라우저 localStorage)에 저장되며,
`남편과 연동`을 켜면 Firebase 실시간 데이터베이스의 같은 방으로 두 사람이 함께 기록합니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| **요약** | 이번 달 저축·누적 저축, 소비 목표 게이지, 계획 vs 실제, 카테고리별 기본예산·전월이월·한도·실제·남은돈 |
| **거래** | 이번 달 거래 내역 — 검색, 지출/수입, 카테고리·결제수단 필터, 날짜별 묶음 |
| **대출** | 총 대출 잔액·상환률·월 예상 이자, 대출별 잔액과 상환이력, `상환 기록` |
| **저축** | 이번 달 저축·누적 저축·월 평균·저축률, 월별 막대, 월별 누적 표 |

PC(900px 이상)에서는 사이드 내비게이션과 2단 대시보드(왼쪽 요약 · 오른쪽 거래 표)로 넓게 보입니다.

## 이월 계산

```
한도(M)      = 기본예산 + 전월이월(M)
남은돈(M)    = 한도(M) − 실제(M)
전월이월(M+1) = 이월 ON ? 남은돈(M) : 0        (초과분 이월 OFF 면 0 아래로 내려가지 않음)
```

`예산·이월 설정`에서 정한 **이월 시작 월**부터 차례로 계산합니다.

## 누적 저축

```
월 저축(M)   = 수입(M) − 지출(M)
누적 저축(M) = 기초 누적 저축 + Σ 월 저축(시작 월 … M)
```

## 엑셀 내보내기

`⋮ → 엑셀(.xlsx) 내보내기` 는 진짜 엑셀 통합문서(OOXML)를 만듭니다 — `월간 요약`, `거래 내역`(모든 기록),
`대출 현황`, `월별 누적 저축` 4장. 외부 라이브러리 없이 브라우저에서 ZIP+XML 을 직접 만듭니다.

## 파일

```
index.html                미리보기용 (샘플 기록 포함, 이 폴더 밖 work/ 에서 생성)
site/                     배포본 — 기록이 전혀 없는 빈 가계부
site/index.html           앱 전체 (CSS·JS 포함 단일 파일)
site/sw.js, manifest...   오프라인·홈 화면 설치
```

## 개인정보

- 이 배포본에는 거래·대출·예산 금액이 하나도 들어 있지 않습니다 (`SAMPLE = null`).
- 기록은 기기 밖으로 나가지 않습니다. 단, `남편과 연동`을 켜면 그 방의 기록만 Firebase 로 갑니다.
- 광고·분석 도구·외부 CDN 을 쓰지 않습니다.
